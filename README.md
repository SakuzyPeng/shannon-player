## 这是什么

香农播放器是一个正在开发中的本地音乐播放器，为珍藏本地音乐文件的人而做——
不追踪、不推流、不打扰，只把你的曲库以舒适的方式呈现出来。

界面依据一套完整的原创设计系统实现，追求安静而耐看的日常质感。

## 特性

- **真实曲库** —— 扫描本地音乐文件夹，自动归拢专辑与合辑；标签写错了能改，且不动原文件
- **无缝换曲** —— 曲目之间不留空隙，整张听的专辑不会被切断
- **响度归一化** —— 把各首的音量拉齐，只在播放时生效，不改写文件
- **输出设备** —— 声音从哪台声卡或耳机出去，在应用里直接选，不必去改系统设置
- **收藏与歌单** —— 攒下来的都留着；整理音乐文件夹、改标签、重扫都不会把它们弄丢
- **曲库浏览** —— 专辑网格与详情列表两种视图自由切换
- **悬浮播放条** —— 播放控制、进度、音量、随机与循环一目了然
- **浅色 / 深色 / 跟随系统** —— 一键循环，深色为整套重新调校的配色
- **多语言** —— 简体中文与 English，随时切换
- **顺手的交互** —— 右键菜单支持键盘导航，细节动效温和不喧宾夺主

> 开发中，尚未发布正式版本。界面已按设计稿全部实现，本地曲库扫描与立体声播放
> 已经可用；多声道与空间音频、更多解码格式仍在路上。进展见下方路线图。
